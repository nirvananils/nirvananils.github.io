01 — Übersicht

Projekte im Überblick

Neben Diagnose und Schulungen entwickle ich eigene Software — rund um die Auswertung von Diagnosedaten, Werkstatt-Tooling und die Verwaltung eines Kleingewerbes. Manche Projekte sind bereits als Open Source auf GitHub veröffentlicht, andere befinden sich noch in Entwicklung oder Planung.

Open Source

Billify

Open-Source-Rechnungsprogramm für deutsche Kleingewerbe — eine Codebasis für Web-App, Windows-Desktop und Android.

  • GoBD-konforme Rechnungen
  • E-Rechnung nach ZUGFeRD / Factur-X
  • Kunden- und Artikelverwaltung
  • Individuelle Rechnungsvorlagen und Umsatzberichte
  • React
  • NestJS
  • PostgreSQL
  • Tauri
Projekt auf GitHub ansehen
Noch nicht veröffentlicht

VCDS Autoscan Parser

Desktop-Tool zur Auswertung von VCDS-Autoscan-Reports aus Fahrzeugen des Volkswagen-Konzerns.

  • Liest Scan-Dateien gesammelt aus einem Ordner ein
  • Speichert die Ergebnisse in einer Datenbank
  • Statistiken zu Steuergeräten, Fehlercodes und Fahrzeugmodellen
  • Erweiterbar über eine eigene Plugin-Engine, z. B. für weitere Diagnose-Formate
  • Python
  • PySide6
  • Plugin-Engine
In Planung

VCDS HV Manager

Geplantes Tool zur Verwaltung und Diagnose von Hochvolt-Systemen in Hybrid- und Elektrofahrzeugen des Volkswagen-Konzerns per VCDS. Das Konzept steht, die Umsetzung hat noch nicht begonnen.

  • Geplant: HV-Batterie
  • Geplant: Ladetechnik
  • Für Hybrid- und Elektrofahrzeuge
  • VCDS
  • Hochvolt
  • E-Mobilität
